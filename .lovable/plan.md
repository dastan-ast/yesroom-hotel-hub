

# План: Добавить функционал синхронизации данных

## Проблема

Сейчас инфраструктура настроена (таблица `platform_settings`, Edge Functions), но:
1. Синхронизация выключена (`sync_enabled: false`)
2. Нет триггеров вызова `sync-to-external`
3. Нет способа запустить синхронизацию

---

## Что будет добавлено

### 1. Кнопка "Синхронизировать сейчас" в SettingsTab

Добавить кнопку для ручной синхронизации всех данных:
- Отправляет все данные из выбранных таблиц во внешний Supabase
- Показывает прогресс и результат

### 2. Лог синхронизации

Добавить отображение результатов последней синхронизации:
- Количество отправленных записей
- Ошибки (если есть)
- Время последней синхронизации

### 3. Автоматическая синхронизация при изменениях

Интегрировать вызов `sync-to-external` в:
- `booking-webhook` (при создании бронирования через API)
- `ManualBookingDialog` (при ручном создании)
- Другие места изменения данных

## Технические изменения

### SettingsTab.tsx - Добавить ручную синхронизацию

```typescript
// Новая функция для синхронизации всех данных
const syncAllData = async () => {
  setSyncing(true);
  
  try {
    // Получить данные из каждой таблицы
    for (const table of settings.sync_tables) {
      const { data, error } = await supabase
        .from(table)
        .select('*');
      
      if (data && data.length > 0) {
        // Отправить во внешний Supabase
        const response = await supabase.functions.invoke('sync-to-external', {
          body: { 
            table, 
            data: data.map(item => ({
              ...item,
              external_id: item.id
            })),
            operation: 'upsert'
          }
        });
      }
    }
    
    toast.success('Синхронизация завершена!');
  } catch (error) {
    toast.error('Ошибка синхронизации');
  } finally {
    setSyncing(false);
  }
};
```
