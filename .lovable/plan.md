
# Настройки аккаунта: смена пароля и email

## Что будет сделано

Создание новой страницы "Настройки аккаунта" (`/account`) с двумя функциями:
1. **Смена пароля** -- отправка ссылки для сброса пароля на текущий email
2. **Смена email** -- изменение email с подтверждением на новый адрес

## Как это будет выглядеть

```text
+------------------------------------------+
|          Настройки аккаунта              |
|                                          |
|  Имя: Иван Иванов                       |
|  Email: user@example.com                |
|                                          |
|  --- Смена пароля ---                    |
|  Мы отправим ссылку для сброса пароля    |
|  на ваш текущий email.                   |
|  [Отправить ссылку для сброса]           |
|                                          |
|  --- Смена email ---                     |
|  Новый email: [____________________]     |
|  [Изменить email]                        |
|                                          |
+------------------------------------------+
```

## Логика работы

### Смена пароля
- Нажатие кнопки вызывает `supabase.auth.resetPasswordForEmail(email)`
- Пользователь получает письмо со ссылкой для установки нового пароля
- После перехода по ссылке открывается форма ввода нового пароля

### Смена email
- Пользователь вводит новый email
- Вызывается `supabase.auth.updateUser({ email: newEmail })`
- Письмо с подтверждением отправляется на **новый** email
- После подтверждения email обновляется

### Обработка ссылки сброса пароля
- На странице `/auth` добавить обработку события `PASSWORD_RECOVERY` через `onAuthStateChange`
- При получении этого события показать форму ввода нового пароля
- Новый пароль устанавливается через `supabase.auth.updateUser({ password: newPassword })`

## Технические детали

- Страница `/account` доступна только авторизованным пользователям (редирект на `/auth` если не авторизован)
- Используются встроенные методы аутентификации: `resetPasswordForEmail`, `updateUser`
- Валидация нового email через zod-схему
- Валидация нового пароля: минимум 6 символов
- Успешные действия отображаются через toast-уведомления
