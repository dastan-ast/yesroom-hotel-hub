
## План: Добавление карусели фотографий в карточки номеров

### Проблема
- База данных содержит поле `images: string[]` для галереи фотографий
- Компонент `RoomCard` принимает только `imageUrl: string | null` (одно фото)
- Гости видят только первое изображение номера

### Решение

#### 1. Обновить RoomCard.tsx
**Изменения:**
- Добавить prop `images: string[] | null`
- Интегрировать компонент `Carousel` из `@/components/ui/carousel`
- При 1 фото — статичное изображение (как сейчас)
- При 2+ фото — карусель со стрелками и индикатором "1/5"

```text
Визуальный результат:
+----------------------------------+
|  [<]   📷 Фото номера     [>]   |
|                                  |
|              1 / 5               |
+----------------------------------+
```

#### 2. Обновить HotelProfile.tsx
- Добавить `images: string[] | null` в интерфейс `RoomType`
- Передавать `room.images` в `RoomCard`

#### 3. Обновить PublicBooking.tsx
- Аналогичные изменения для совместимости

### Файлы для изменения

| Файл | Действие |
|------|----------|
| `src/components/RoomCard.tsx` | Добавить карусель Embla |
| `src/pages/HotelProfile.tsx` | Передавать images в RoomCard |
| `src/pages/PublicBooking.tsx` | Передавать images в RoomCard |

### Технические детали

**RoomCard логика отображения:**
```
1. Собрать все фото: images[] + fallback на imageUrl
2. Если 0 фото → placeholder
3. Если 1 фото → статичное изображение
4. Если 2+ фото → Carousel с навигацией
```

**Компоненты карусели:**
- `Carousel`, `CarouselContent`, `CarouselItem` — контейнер
- `CarouselPrevious`, `CarouselNext` — стрелки навигации
- Кастомный индикатор "текущий / всего"

### Результат
- Гости смогут пролистывать все фотографии номера
- Стрелки навигации внутри карточки
- Индикатор текущего слайда
- Поддержка свайпа на мобильных устройствах
