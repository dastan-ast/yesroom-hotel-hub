
# Оплата за PMS и уведомления о подписке для владельцев

## Что будет сделано

### 1. Обновление страницы "Тарифы" (`/pricing`)
Текущая страница содержит общую информацию. Добавим конкретные тарифные планы с ценами, которые SuperAdmin может настраивать через `platform_settings`:

- Отображение тарифных планов (например: Базовый, Стандарт, Премиум) с ценами
- Кнопка "Связаться для оплаты" (ручное управление -- без онлайн-оплаты)
- Цены и описания тарифов берутся из таблицы `platform_settings`

### 2. Настройка тарифов в SuperAdmin
В существующей вкладке "Настройки" (`SettingsTab`) SuperAdmin сможет:
- Создавать/редактировать тарифные планы (название, цена, описание, список возможностей)
- Планы сохраняются в `platform_settings` с ключом `pricing_plans`

### 3. Баннер-уведомление в админ-панели владельца
В `AdminDashboard.tsx` добавить постоянный баннер вверху страницы, показывающий:
- Текущий статус подписки (Пробный / Активный / Истёк / Приостановлен)
- Оставшиеся дни пробного периода
- Предупреждение при истечении < 3 дней
- Кнопка "Связаться" или "Перейти к тарифам"

### 4. Вкладка "Подписка" в боковом меню админ-панели
Новая вкладка для владельцев с подробной информацией:
- Текущий статус и дата окончания
- История изменений подписки (из `subscription_history`)
- Ссылка на страницу тарифов
- Контактная информация для оплаты

## Техническая реализация

### Баннер подписки (`SubscriptionBanner.tsx`)
- Получает данные отеля (`subscription_status`, `trial_ends_at`) через props из `AdminDashboard`
- Цветовая индикация: зелёный (active), синий (trial), красный (expired), серый (suspended)
- Для `trial`: показывает "Пробный период: X дней осталось"
- Для `expired`/`suspended`: красный баннер с призывом к действию
- Виден только владельцам (`isOwner`)

### Вкладка "Подписка" (`SubscriptionTab.tsx`)
- Карточка с текущим статусом, датой начала/окончания
- Таблица истории изменений из `subscription_history` (владельцы уже имеют RLS-доступ на SELECT)
- Кнопка "Посмотреть тарифы" -> `/pricing`
- Доступна только владельцам

### Тарифные планы в `platform_settings`
- Ключ: `pricing_plans`
- Формат: JSON-массив с объектами `{ name, price, period, features[], highlighted }`
- SuperAdmin редактирует через форму в `SettingsTab`
- Страница `/pricing` читает через публичный доступ (потребуется RLS-политика для анонимного чтения `platform_settings` с фильтром по ключу `pricing_plans`)

### Миграция базы данных
- Добавить RLS-политику на `platform_settings` для публичного чтения записи с ключом `pricing_plans`
- Вставить начальные тарифные планы в `platform_settings`

### Маршрутизация в `AdminDashboard`
- Новый пункт меню "Подписка" с иконкой `CreditCard`, доступен только для `isOwner`
- Располагается перед "Справка" в меню
