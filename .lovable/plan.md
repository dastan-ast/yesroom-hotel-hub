

# Объединение Шахматки и Очереди бронирований + Отчётность

## Обзор
Улучшение модуля Шахматка, чтобы он стал основным рабочим инструментом администратора: добавление кнопки бронирования, интерактивных ячеек с модальными окнами, очистка визуального шума, и новый раздел отчётности по загрузке для владельца.

---

## 1. Кнопка бронирования в Шахматке

Добавить кнопку "+ Новое бронирование" в заголовок шахматки, которая открывает уже существующий `ManualBookingDialog`. После успешного бронирования -- данные шахматки обновляются автоматически.

**Файл:** `src/components/admin/ShahmatkaGrid.tsx`
- Импортировать `ManualBookingDialog`
- Добавить состояние `dialogOpen`
- Кнопка рядом с навигацией по датам
- Callback `onSuccess` вызывает `fetchData()`

---

## 2. Клик по бронированию -- открытие карточки клиента

При нажатии на цветную ячейку в шахматке открывается существующий `BookingDetailModal` (тот же, что в очереди бронирований -- с информацией, услугами и счётом).

**Файл:** `src/components/admin/ShahmatkaGrid.tsx`
- Добавить состояние `selectedBookingId` и `detailModalOpen`
- Сделать цветные ячейки (left/right half) кликабельными (`cursor-pointer`, `onClick`)
- При клике -- открывать `BookingDetailModal` с `bookingId` и `hotelId`

---

## 3. Очистка визуального шума в строках номеров

Убрать тип номера из постоянного отображения. Показывать только номер комнаты. Тип появляется при наведении (tooltip).

**Файл:** `src/components/admin/ShahmatkaGrid.tsx`
- Удалить строку `<div className="text-xs text-muted-foreground">{room.room_types?.name}</div>` из ячейки номера
- Добавить `title={room.room_types?.name || ''}` на `<td>` с номером, чтобы тип показывался при наведении
- Использовать `Tooltip` компонент для более красивого отображения

---

## 4. Убрать имена, показывать при наведении

Убрать текстовые overlay с именами гостей из ячеек. Вместо этого при наведении на цветную ячейку показывать tooltip сверху с именем гостя и статусом на русском.

**Файл:** `src/components/admin/ShahmatkaGrid.tsx`
- Удалить блок рендеринга `spanForCell` (overlay с именем)
- Заменить `title` атрибуты на русскоязычные: `"Иванов Иван — Заселён"` вместо `"Иванов Иван (checked_in)"`
- Маппинг статусов на русский: `{ pending: 'Ожидает', approved: 'Подтверждено', checked_in: 'Заселён', checked_out: 'Выселен', cancelled: 'Отменено' }`

---

## 5. Отчётность по загрузке для владельца

Добавить новый блок в `ExecutiveDashboard` (вкладка "Аналитика") -- таблица загрузки номеров за выбранный период.

**Файл:** `src/components/admin/ExecutiveDashboard.tsx`
- Добавить секцию "Отчёт по номерам" с выбором периода (DatePicker: дата начала и конца)
- Таблица: Номер комнаты | Тип | Дней занят | Дней свободен | % загрузки
- Итоговая строка: общая загрузка отеля за период
- Данные считаются из bookings (approved + checked_in + checked_out) за выбранный диапазон

---
