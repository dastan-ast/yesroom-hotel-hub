
# Добавление подтверждения email при регистрации

## Текущее состояние
Сейчас после регистрации пользователь сразу получает сообщение "Регистрация успешна!" и перенаправляется в приложение. Подтверждение email не требуется.

## Что будет сделано

### 1. Экран "Проверьте почту"
После успешной регистрации вместо автоматического входа пользователь увидит экран с сообщением о необходимости подтвердить email:

```text
+----------------------------------+
|        Проверьте почту           |
|                                  |
|    [иконка письма]               |
|                                  |
|  Мы отправили письмо на          |
|  user@example.com                |
|                                  |
|  Перейдите по ссылке в письме    |
|  для подтверждения аккаунта      |
|                                  |
|  [Вернуться ко входу]            |
+----------------------------------+
```

### 2. Обработка подтверждения
Когда пользователь нажимает ссылку в письме, он попадает обратно на `/auth` -- система распознает подтвержденную сессию и перенаправляет по стандартной логике (admin/guest/onboarding).

### 3. Сообщение при входе без подтверждения
Если пользователь попытается войти до подтверждения email, он увидит понятное сообщение: "Подтвердите email перед входом".

## Файлы для изменения

| Файл | Изменение |
|------|-----------|
| `src/pages/Auth.tsx` | Добавить состояние "email отправлен", экран подтверждения, обработка ошибки "Email not confirmed" |
| `src/contexts/AuthContext.tsx` | Обновить `signUp` -- не делать автоматический вход после регистрации, вернуть информацию о необходимости подтверждения |

## Техническая реализация

### Auth.tsx
- Добавить состояние `emailSent` с адресом email
- После успешной регистрации показать экран "Проверьте почту" вместо редиректа
- Убрать `pendingRedirect` при регистрации -- редирект произойдет только после подтверждения и входа
- Добавить обработку ошибки `Email not confirmed` при попытке входа

### AuthContext.tsx
- В функции `signUp` параметр `emailRedirectTo` уже настроен -- письмо будет отправлено автоматически
- Убедиться что после `signUp` не происходит автоматический вход (Lovable Cloud по умолчанию требует подтверждение)
