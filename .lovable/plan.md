
# Исправление шахматки и редактирование времени полсуток

## Проблема 1: Имена не отображаются в шахматке

**Причина**: Текущий код использует невалидный CSS `calc()` для позиционирования имён. Выражение `calc(112px + ${leftPercent}% * (100% - 112px) / 100)` -- некорректный синтаксис CSS (нельзя умножать проценты таким образом). Кроме того, `<td>` с `position: absolute` внутри `<tr>` не работает корректно в таблицах.

**Решение**: Заменить оверлей имён на `<div>` элементы внутри обёртки с `position: relative`. Использовать JavaScript-расчёт позиции через `ref` на таблице, либо упростить подход -- рендерить имя гостя прямо внутри ячеек (первой ячейке бронирования), используя `colSpan`-подобную логику через абсолютно позиционированный `div` внутри ячейки с точным расчётом ширины.

Конкретно:
- Обернуть каждую строку в контейнер с `position: relative`
- Имена рендерить как `<div>` (не `<td>`) с `position: absolute`
- Позиционирование рассчитывать через процент от ширины области дат: `left = (startIdx / 7) * 100%`, `width = (span / 7) * 100%`
- Для check-in дня смещать на 50% ячейки вправо (начало с 12:00)
- Для half-day -- ширина = 50% ячейки

## Проблема 2: Редактирование времени заселения для полсуток

**Текущее поведение**: При `is_half_day = true` время фиксировано 12:00-00:00, без возможности изменить.

**Решение**: Добавить поле выбора времени заселения (выпадающий список часов) при `is_half_day = true`. Время выезда автоматически = время заселения + 12 часов. Например: заселение в 14:00 -> выезд в 02:00 следующего дня.

## Техническая реализация

### ShahmatkaGrid.tsx -- исправление имён

Текущий сломанный код (строки 350-384) будет заменён:

- Вместо `<td>` оверлеев -- использовать структуру с двумя слоями внутри каждой строки:
  1. Слой ячеек (существующие `<td>` с цветными половинками) -- без изменений
  2. Слой имён -- `<div>` с `position: absolute` внутри контейнера, который оборачивает область дат строки

- Конкретная реализация: после всех `<td>` ячеек дней, добавить абсолютно позиционированный контейнер поверх ячеек дат. Имена внутри него позиционируются через `left` и `width` в процентах от ширины контейнера дат.

- Формулы:
  - Для обычного бронирования: `left = (startIdx * 100/7 + 100/7/2)%` (начало с правой половины check-in), `width = ((span-1) * 100/7)%` + корректировка для check-out
  - Для half-day: `left = (startIdx * 100/7 + 50%)`, `width = 50% ячейки`

### ManualBookingDialog.tsx -- выбор времени

- Добавить состояние `halfDayCheckInHour` (число 0-23, по умолчанию 12)
- При `is_half_day = true` показать Select с часами (например: 08:00, 09:00, ..., 23:00)
- Автоматически рассчитывать и показывать время выезда: `checkInHour + 12` (с переносом на следующий день если > 24)
- Время выезда отображается рядом как информационное поле
- Значение часа сохраняется в `additional_info` бронирования (поле JSONB уже существует)
