
# Аналитика, Шахматка и полусуточное размещение

## 1. Аналитика -- круговая диаграмма статусов номеров

### Что изменится
В `ExecutiveDashboard.tsx` будет добавлена круговая диаграмма (PieChart из recharts) с распределением номеров по статусам: **Заселены**, **Забронированы**, **Ожидают**, **Свободны** -- в количестве и процентах, рядом количество.

### Переключатель периода
- **За 7 дней** -- агрегация данных за последние 7 дней (среднее за период)
- **За текущий месяц** -- агрегация за текущий календарный месяц

Для каждого периода будет рассчитано среднее количество номеров в каждом статусе по дням. Данные берутся из таблицы `bookings` с привязкой к `rooms`.

### UI
- Новая секция "Распределение номеров" под основными карточками
- Круговая диаграмма (recharts `PieChart`) с легендой
- Переключатель "7 дней / Месяц" над диаграммой
- Цвета: зеленый (заселены), синий (забронированы), желтый (ожидают), серый (свободны)

## 2. Шахматка -- визуализация суток 12:00-12:00 и центрирование имени

### Что изменится в `ShahmatkaGrid.tsx`

**Разделение суток на две половины:**
Каждая ячейка дня будет разделена на две половины (утро до 12:00 и после 12:00). Бронирования будут окрашивать:
- День заезда: только правую половину ячейки (с 12:00)
- Промежуточные дни: полностью
- День выезда: только левую половину (до 12:00)

Это визуально отражает расчётный час 12:00.

**Имя гостя по центру:**
Имя гостя будет отображаться один раз, растянутое по центру всех занятых ячеек бронирования. Для этого будет использован CSS с `position: absolute` и расчёт ширины через `colspan`.

**Полусуточное размещение:**
Если бронирование помечено как `is_half_day = true`, ячейка окрашивается на половину (только вторая половина дня заезда -- с 12:00 до 00:00).

## 3. Check-in / Check-out по умолчанию с 12:00

### Что изменится
- В `ManualBookingDialog.tsx` -- при создании бронирования время check-in устанавливается по умолчанию на 12:00, check-out на 12:00 следующего дня
- В `BookingDetailModal.tsx` -- отображение времени заезда/выезда
- Это влияет только на визуальное отображение и логику шахматки, даты в БД остаются без изменений (формат `date`)

## 4. Бронирование на полсуток (12 часов)

### Миграция базы данных
Добавить колонку `is_half_day` (boolean, default false) в таблицу `bookings`.

### Что изменится в UI
- В `ManualBookingDialog.tsx` -- чекбокс "Полусуточное размещение (12 часов)"
- Если выбрано: check-out автоматически = check-in дата (тот же день), визуально гость занимает номер с 12:00 до 00:00
- В `BookingDetailModal.tsx` -- отображение метки "Полсуток"
- В `ShahmatkaGrid.tsx` -- ячейка окрашивается на 50% ширины (правая половина)

## Техническая реализация

### PieChart (ExecutiveDashboard)
- Используется `recharts` (уже установлен): `PieChart`, `Pie`, `Cell`, `Legend`, `Tooltip`
- Данные рассчитываются за выбранный период: для каждого дня определяется сколько номеров в каждом статусе, затем берётся среднее
- Статусы номеров определяются динамически из `bookings` (checked_in = заселён, approved = забронирован, pending = ожидает, остальные = свободен)

### Шахматка -- разделение ячеек
- Каждая `td` содержит два `div` (левая и правая половина)
- Левая = утро до 12:00 (может быть окрашена цветом check-out предыдущего гостя)
- Правая = после 12:00 (окрашена цветом check-in нового гостя)
- Промежуточные дни: обе половины одного цвета
- Для `is_half_day`: только правая половина

### Имя гостя
- Используется `position: relative` на строке и `position: absolute` для блока с именем
- Имя рассчитывается через `getBookingSpan()` -- количество ячеек от check-in до check-out
- Показывается один раз, центрируется по горизонтали на всю длину бронирования

### Миграция
```sql
ALTER TABLE public.bookings ADD COLUMN is_half_day boolean NOT NULL DEFAULT false;
```
