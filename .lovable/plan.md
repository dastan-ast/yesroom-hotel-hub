
## План: Создание PDF-инструкции для администратора со скриншотами

### Обзор задачи
Создать интерактивную страницу справки в админ-панели, которую можно распечатать как PDF или экспортировать с иллюстрациями интерфейса.

---

### Подход к реализации

#### Вариант 1: Встроенная страница справки с функцией печати (Рекомендуемый)
Создаём отдельную вкладку "Справка" в админ-панели со стилями для печати:

**Преимущества:**
- Всегда актуальная информация
- Не требует внешних библиотек
- Простая печать в PDF через браузер (Ctrl+P → Сохранить как PDF)

**Компоненты:**
- Раздел "Справка" (`HelpTab.tsx`)
- Заготовленные скриншоты интерфейса
- CSS стили для печати (@media print)

---

### Технический план

#### 1. Создание статических скриншотов
Подготовить изображения ключевых разделов:
- `help-room-types.png` — Таблица типов номеров
- `help-rooms.png` — Сетка номеров с цветовой легендой  
- `help-bookings.png` — Очередь бронирований
- `help-manual-booking.png` — Форма ручного бронирования
- `help-shahmatka.png` — Визуальная сетка занятости
- `help-room-dialog.png` — Диалог редактирования номера

#### 2. Новый компонент HelpTab.tsx
```
src/components/admin/HelpTab.tsx
```

**Содержание:**
- Пошаговые инструкции с заголовками
- Встроенные изображения с подписями
- Кнопка "Распечатать / Сохранить PDF"
- Таблица статусов и цветов
- FAQ по частым вопросам

**Структура документа:**
```text
1. Начало работы
   1.1 Создание типов номеров (+ скрин)
   1.2 Добавление номеров (+ скрин)
   
2. Управление бронированиями
   2.1 Новая заявка из интернета
   2.2 Ручное бронирование (+ скрин)
   2.3 Назначение номера
   2.4 Заселение / Выселение
   2.5 Отмена бронирования
   
3. Работа с Шахматкой
   3.1 Просмотр занятости (+ скрин)
   3.2 Цветовая кодировка
   
4. Клиентская база
   4.1 Поиск по телефону
   4.2 История бронирований гостя
   
5. Статусы и цвета
   - Таблица: статус → цвет → описание
```

#### 3. Стили для печати
```css
@media print {
  /* Скрыть навигацию и кнопки */
  .sidebar, .header, button { display: none; }
  
  /* Показать только контент справки */
  .help-content { 
    width: 100%;
    padding: 0;
  }
  
  /* Разрывы страниц перед разделами */
  .help-section { page-break-before: always; }
  .help-section:first-child { page-break-before: avoid; }
  
  /* Изображения на всю ширину */
  .help-screenshot {
    max-width: 100%;
    border: 1px solid #ddd;
  }
}
```

#### 4. Добавление в меню AdminDashboard
```typescript
// В menuItems добавить:
{ id: 'help', icon: HelpCircle, label: 'Справка' }

// В render:
{activeTab === 'help' && <HelpTab />}
```

### Результат

После реализации:
- В админ-панели появится вкладка **"Справка"** с иконкой `?`
- Внутри — полная инструкция с изображениями
- Кнопка **"Скачать PDF"** откроет окно печати браузера
- При выборе "Сохранить как PDF" — создаётся документ со всеми скринами
