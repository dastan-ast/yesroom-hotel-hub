
# Маркетинговая презентация YesRoom PMS

## Описание
Создание новой страницы `/presentation` с 5 слайдами в стиле полноэкранной презентации для привлечения отелей. Каждый слайд занимает полный экран (100vh) с плавной прокруткой между ними. Дизайн выдержан в фирменном стиле (dark navy + gold accents).

## Структура слайдов

### Слайд 1 -- Титульный
- Логотип YesRoom (крупный, по центру)
- Заголовок: "Современная система управления отелем"
- Подзаголовок: "Прямые бронирования. Удобное управление. Без комиссий."
- Кнопка "Начать бесплатно" и "Узнать больше" (скролл вниз)

### Слайд 2 -- Проблема и Решение
- Левая колонка: "Без YesRoom" -- список проблем отельеров (ручной учёт, комиссии OTA, хаос в бронированиях, потеря данных)
- Правая колонка: "С YesRoom" -- решения (автоматизация, прямые бронирования, шахматка, CRM)
- Иконки для каждого пункта

### Слайд 3 -- Возможности системы (с визуальными карточками)
- 6 карточек с иконками:
  1. Шахматка (календарь загрузки)
  2. Онлайн-бронирование (страница отеля)
  3. CRM клиентов (история гостей)
  4. Аналитика (графики и отчёты)
  5. Услуги (допродажи, счета)
  6. Интеграции (API, Telegram, WhatsApp)
- Каждая карточка с кратким описанием и иконкой

### Слайд 4 -- Надёжность и безопасность
- Метрики в крупных числах:
  - "99.9% Uptime"
  - "SSL шифрование"
  - "Ежедневные бэкапы"
  - "Облачная инфраструктура"
- Блок с текстом о защите данных гостей и RLS-политиках (в доступных формулировках)
- Бейджи: "Казахстан", "Cloud", "24/7"

### Слайд 5 -- Призыв к действию
- "Начните управлять отелем эффективно"
- Шаги подключения (3 шага): Регистрация -> Настройка -> Приём бронирований
- Кнопки: "Зарегистрироваться бесплатно" и "Связаться с нами"
- Контактная информация / ссылки на соцсети

## Техническая реализация

| Файл | Действие |
|------|----------|
| `src/pages/Presentation.tsx` | Новый файл -- страница презентации |
| `src/App.tsx` | Добавить маршрут `/presentation` |
| `src/components/Navbar.tsx` | Добавить ссылку "Презентация" в навигацию |

### Детали реализации

- Каждый слайд -- `section` с `min-h-screen` и `snap-start`
- Контейнер с `scroll-snap-type: y mandatory` для плавной навигации
- Навигационные точки (dots) справа для быстрого перехода между слайдами
- Анимации появления элементов при скролле через `IntersectionObserver`
- Адаптивная верстка: на мобильных карточки стекаются вертикально
- Без внешних зависимостей -- только Tailwind, Lucide иконки, и существующие UI-компоненты
- Navbar скрыт на этой странице для полноэкранного эффекта, но есть кнопка "Назад"
